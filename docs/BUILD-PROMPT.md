# 00338.com — Phase-wise Build Prompt

Use these prompts in order with an AI coding assistant (or a developer). Each phase is self-contained and ends with acceptance checks. Phases 1–6 are **already implemented in this repository**; phases 7–10 are the growth roadmap.

---

## Global brief (paste at the top of every phase)

> You are building **00338 Number Lab** on the domain **00338.com**: the web's most useful, honest reference for **numbers in Chinese culture** — what any number means (Mandarin *and* Cantonese), how lucky it is, and what lucky numbers are worth — plus a **Lucky Number Desk** that turns high-intent visitors into leads (lucky phone numbers, licence plates, numeric domains, naming/date consultations).
>
> **Constraints**
> - Static site, zero backend, deployable on the **free GitHub Pages** plan (public repo). Plain HTML/CSS/vanilla JS, generated by a dependency-free Node build script. All internal links **relative** (works under `/<repo>/` and on the custom domain).
> - Modern, fast, accessible (WCAG AA), responsive from 320px, light + dark themes, no horizontal scroll, Core Web Vitals friendly (fixed-height ad slots, no layout shift, lazy YouTube).
> - **Top bar on every page:** "Contact, if you are interested in this website / domain name / Sponsorship / Advertisement / Partnership" linking to `https://web.works/contact`.
> - **One private inbox** receives every form and contact. It must **never appear in HTML or source as plain text**: store it XOR-encoded in JS, decode only at submit/click time, post forms through FormSubmit's AJAX endpoint (or an alias), fall back to a JS-built `mailto:`.
> - **Trademark hygiene:** "00338" is used as a number only. Never use the name, logo or data of any company whose identifiers contain 00338 (e.g. the HK-listed company with that stock code). Include a Trademark & Copyright Disclosure page and footer notice.
> - Monetisation: Google AdSense (consent-gated), YouTube embeds, affiliates, sponsorships, paid reports/consults, donations, contests.
> - Design: warm off-white `#FBF8F3`, ink `#1B1613`, lucky red `#C8102E`, gold `#C9971C`, jade (lucky) / amber (mixed) / red (unlucky) verdict colours; Noto Serif SC headings, Inter body, JetBrains Mono for digits — the digits are the hero.

## Phase 7 — Launch checklist (owner)
1. Point DNS for 00338.com to GitHub Pages (A records 185.199.108–111.153, `www` CNAME → `webworksa1.github.io`), set the custom domain in **Settings → Pages**, tick **Enforce HTTPS**.
2. Submit the first form yourself and click FormSubmit's activation email; paste the alias into `config.js → formAlias`.
3. Google Search Console + Bing Webmaster: verify, submit `sitemap.xml`.
4. Apply for AdSense after ~20–30 days of indexed traffic; add publisher ID to `config.js` and uncomment `ads.txt`.
